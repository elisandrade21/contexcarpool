# Contextual Assistance for Users of Ridesharing Services (AINA-2027)

ContexCarpool: explainable ranking of peer-carpooling offers with an OWL context model, SHACL, SPARQL 1.1 rules and PROV-O, on a server or in a mobile browser.

Authors: Elisa de Fátima Andrade Soares, Breno José Ribeiro de Vasconcelos, Carlos André Guimarães Ferraz (CIn/UFPE).

## Paper

- Main document: `paper-AINA.tex` (Springer `svproc` template; build with `latexmk -pdf paper-AINA.tex`)
- Bibliography: `refs.bib` with `spmpsci.bst`
- `\anonfalse` / `\anontrue` in the preamble switches between the named and the anonymous version.

## Code and data (`code/`)

| Path | Content |
|---|---|
| `code/ontology/ridesharing.ttl` | OWL domain ontology (schema.org and PROV-O alignment) |
| `code/ontology/rules.ru` | Reasoning rules R1–R8 as SPARQL 1.1 Update (reference), with qualified PROV-O records |
| `code/ontology/rules.rules` | Equivalent Jena forward rules |
| `code/ontology/shapes.ttl` | SHACL input contract |
| `code/experiment/sparql/` | SPARQL: cost percentiles (update), ranking and rationales (CQ1), CQ2–CQ4, contrastive explanation (CQ5) |
| `code/experiment/run_experiment.py` | Synthetic benchmark (seeded), reference implementation and all analyses |
| `code/experiment/jena/Validate.java` | Verification with Apache Jena 4.10 (SPARQL rules vs Jena rules vs reference, OWL consistency, SHACL, latency) |
| `code/experiment/rq1_redundancy.py` | RQ1: redundancy test (cross-validated R², ablation τ), with the counterexample |
| `code/experiment/data_stability.py` | RQ2: ranking stability under perturbation of the offers' data |
| `code/experiment/calibrated_france.py` | France scenario calibrated from published statistics of real BlaBlaCar listings (Farajallah et al. 2019; Lambin & Palikot 2026; Blayac et al. 2026) |
| `code/experiment/tamper_audit.py` | Third-party audit in rdflib: detection of planted ranking manipulations |
| `code/experiment/crosscheck_rdflib.py` | Same SPARQL files re-executed in rdflib (engine independence) |
| `code/experiment/service/RankService.java` | Stateless HTTP ranking service (`POST /rank`) |
| `code/experiment/load_test.py` | HTTP load test (1, 4, 8 concurrent clients) |
| `code/experiment/out/*.json` | Results reported in the paper |

## Mobile client (ContexCarpool)

`code/ontology/rules_context.ru` and `code/experiment/sparql/cq6_context_notes.rq` add the device-context rules R9-R13. `code/ontology/rules_settlement.ru` and `code/experiment/sparql/cq8_settlement.rq` settle the fare after the trip (R14-R15); `cq7_personal_view.rq` is the personal view. `code/experiment/mobile/` holds the page, the data export and the Oxigraph, rdflib and Jena checks.

```bash
cd code
python3 experiment/mobile/export_searches.py
python3 experiment/mobile/context_data.py
python3 experiment/mobile/real_registry.py
python3 experiment/mobile/settlement_data.py
python3 experiment/mobile/settlement_sensitivity.py
node experiment/mobile/cq7check.mjs <node_modules>/oxigraph/node.js
node experiment/mobile/crosscheck_oxigraph.mjs <node_modules>/oxigraph/node.js
node experiment/mobile/rationale_check.mjs <node_modules>/oxigraph/node.js 8765   # needs the service running; same rationale text on server and phone engine
python3 experiment/mobile/crosscheck_context.py
java -cp ".tools/apache-jena-4.10.0/lib/*" experiment/mobile/ContextCheck.java
python3 experiment/mobile/build_web.py <node_modules>
java -cp ".tools/apache-jena-4.10.0/lib/*" experiment/service/RankService.java 8765 0.0.0.0
```

Semi-real scenario: `python3 experiment/mobile/real_registry.py` adds 30 searches with real departure points, times and distances from the French carpool registry (Registre de preuve de covoiturage, data.gouv.fr, Licence Ouverte; sample of 1–6 October 2026 in `code/experiment/out/registry_sample.csv.gz`). Price, seats and booking stay modelled.

## Reproduce

```bash
cd code
pip install -r requirements.txt
python3 experiment/run_experiment.py
# Apache Jena 4.10 binary distribution unpacked in code/.tools/ (Java 11+)
java -cp ".tools/apache-jena-4.10.0/lib/*" experiment/jena/Validate.java
python3 experiment/crosscheck_rdflib.py
python3 experiment/rq1_redundancy.py
python3 experiment/data_stability.py
python3 experiment/tamper_audit.py
python3 experiment/omission_attack.py       # what recomputation cannot see: hidden or fake offers
python3 experiment/baselines.py             # price and price-per-km orderings vs S
python3 experiment/calibrated_france.py
# HTTP service and load test
java -cp ".tools/apache-jena-4.10.0/lib/*" experiment/service/RankService.java 8080 &
python3 experiment/load_test.py 8080
```

Data are synthetic (fixed seeds) except the sample of the French carpool registry; every number in the paper is regenerated by the commands above, except the phone measurements of RQ4 (`code/experiment/out/mobile_runs/`).

## Screening of AINA papers

`screening/aina_2017_2026_screening.csv` lists the candidates kept after a title screening of the 2,406 AINA 2017–2026 papers (main track and workshops) and the reading of about 120 abstracts. Relevance is a single reviewer's judgment. Group codes: MOB = mobility, REC = recommendation, ONT = ontologies and semantic web.
