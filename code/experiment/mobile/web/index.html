This phone recomputes the scores and the order with its own engine and compares them with what the server published. It shows that the output follows the public rules and data, not that the data are true.

Fare after the trip

Each phone records how far the passenger travelled on the top offer. Both phones run the same public rule (R14-R15): if the two records agree within 5% of the trip, the fare is prorated; otherwise the trip is disputed.
